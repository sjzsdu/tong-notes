## 主要技术领域

### React
React 是由 Facebook 开发的用于构建用户界面的 JavaScript 库。它采用组件化的开发模式，具有虚拟 DOM、单向数据流等特性。

### Angular
Angular 是由 Google 开发的前端框架，提供了完整的解决方案，包括 TypeScript、依赖注入、模块化等特性。

### React JSON Schema
React JSON Schema 是一个基于 JSON Schema 的 React 组件库，用于快速构建表单和 UI 界面。
