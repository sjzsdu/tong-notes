# A2A 文档中文版

这是Agent2Agent (A2A) 协议官方文档的中文版本。A2A 是一个开放协议，实现AI代理间的标准化通信和协作。

## 主要特性

- **标准化通信** - 基于JSON-RPC 2.0和HTTP(S)
- **代理发现** - 通过Agent Card描述和发现能力
- **多种交互模式** - 同步、流式、异步推送
- **企业级安全** - 支持多种认证和加密机制
- **多语言SDK** - Python、JavaScript、Java、.NET
