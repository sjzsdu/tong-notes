# 提示工程核心知识与实践经验

## 一、提示工程基础原理

### 1. 黄金法则
> **清晰直接是王道**：Claude 只知道你明确告诉它的信息，没有额外的上下文。

**实用技巧**：
- 将提示给朋友看，如果他们能按照指令完成任务，Claude 也能
- 避免模糊表达，具体说明期望的行为
- 直接要求想要的结果，而不是暗示

### 2. 基本结构要求
```
用户消息 → 助手回复 → 用户消息 → 助手回复...
```
- 必须以用户消息开始
- 用户和助手消息必须交替出现
- 可以预填充助手消息来引导回复

## 二、系统提示（System Prompt）最佳实践

### 核心作用
- 设定 Claude 的角色和行为准则
- 提供全局上下文和指导原则
- 定义输出格式和风格要求

### 设计原则
```python
# 角色定义示例
SYSTEM_PROMPT = """你是一个专业的数据分析师。
你需要：
1. 用清晰的逻辑分析数据
2. 提供可操作的建议
3. 承认不确定性时要诚实
4. 使用专业但易懂的语言"""
```

## 三、复杂提示结构化框架

### 标准10要素结构
```python
# 1. 任务上下文 (Task Context)
# 定义 Claude 的角色和总体目标

# 2. 语调上下文 (Tone Context)  
# 指定回复的语调和风格

# 3. 任务描述与规则 (Task Description & Rules)
# 详细说明具体任务和约束条件

# 4. 示例 (Examples)
# 提供few-shot示例来指导行为

# 5. 输入数据 (Input Data)
# 需要处理的具体数据

# 6. 即时任务 (Immediate Task)
# 重申当前需要完成的具体任务

# 7. 预认知 (Precognition)
# 要求分步思考："在回答之前，先思考..."

# 8. 输出格式 (Output Formatting)
# 指定回复的具体格式要求

# 9. 预填充 (Prefilling)
# 为助手消息提供开头，引导回复方向

# 10. 组合逻辑
# 将以上元素按最佳顺序组合
```

### 实战模板
```python
def build_complex_prompt(context, task, examples, data):
    prompt = f"""
{context}

{task}

以下是一些示例：
{examples}

需要处理的数据：
{data}

请按照以下格式回复：
<分析>
你的分析过程
</分析>

<结论>
最终结论
</结论>

在开始分析之前，请先思考解决步骤。
"""
    return prompt
```

## 四、核心技术要点

### 1. 角色提示（Role Prompting）
```python
# 基础角色设定
"你是一个逻辑推理专家，擅长解决复杂的逻辑问题。"

# 高级角色设定（包含具体能力和限制）
"""你是AdAstra职业指导公司的AI顾问Joe。
你的目标是为用户提供职业建议。
你应该：
- 保持友好的客服语调
- 专注于职业相关问题
- 承认不确定时要诚实
- 如果问题无关，礼貌地重新引导话题"""
```

### 2. 数据与指令分离
```xml
<!-- 使用XML标签清晰分离 -->
<指令>
请分析以下客户评论的情感倾向

<数据>

<格式>
情感：[正面/负面/中性]
置信度：[高/中/低]
关键词：[列出3-5个关键词]
</格式>
```

### 3. Few-Shot示例技术

## 五、实战经验总结

### 1. 常见错误与解决方案

**错误1：提示过于简单**
```python
# 错误示例
"写一首诗"

# 改进示例  
"写一首关于秋天的七言绝句，要求：
- 体现秋天的萧瑟感
- 包含自然景物描写
- 情感真挚，朗朗上口
- 直接输出诗歌，不要前言"
```

**错误2：指令与数据混淆**
```python
# 错误示例
"分析这段文本：客户说产品很好用，请判断情感"

# 改进示例
"""<任务>
分析客户评论的情感倾向
</任务>

<评论>
客户说产品很好用
</评论>"""
```

### 2. 性能优化技巧

**提示链（Prompt Chaining）**
```python
# 第一步：提取关键信息
step1 = "从以下文本中提取关键信息：{text}"

# 第二步：基于提取的信息进行分析
step2 = "基于以下关键信息进行深度分析：{extracted_info}"

# 第三步：生成最终结论
step3 = "基于分析结果，给出具体建议：{analysis}"
```

**动态调整策略**
```python
def adaptive_prompt(task_complexity, user_expertise):
    if task_complexity == "high" and user_expertise == "beginner":
        return "请用简单易懂的语言，分步骤详细说明..."
    elif task_complexity == "high" and user_expertise == "expert":
        return "请提供技术细节和高级见解..."
    else:
        return "请提供标准的分析结果..."
```

### 3. 质量控制方法

**输出验证**
```python
# 在提示中加入自我检查
"完成分析后，请检查：
1. 是否遗漏重要信息？
2. 逻辑是否自洽？
3. 结论是否有足够支撑？
如果发现问题，请修正后再给出最终答案。"
```

**错误处理**
```python
# 预设错误处理策略
"如果你不确定答案，请说'我需要更多信息'。
如果问题超出你的能力范围，请诚实告知。
如果数据不完整，请指出缺失的关键信息。"
```
