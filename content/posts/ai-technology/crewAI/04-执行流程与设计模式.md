# CrewAI 执行流程与设计模式

## 核心设计模式

CrewAI采用了多种经典设计模式来确保代码的可维护性、可扩展性和模块化。

## 任务执行流程图

```mermaid
sequenceDiagram
    participant CLI as CLI命令
    participant CrewManager as Crew管理器
    participant ProcessStrategy as 流程策略
    participant Agent as 智能体
    participant TaskExecutor as 任务执行器
    participant LLM as 语言模型
    participant ToolManager as 工具管理器
    participant EventBus as 事件总线

    CLI->>CrewManager: kickoff(inputs)
    CrewManager->>EventBus: publish(CrewStartedEvent)

    CrewManager->>ProcessStrategy: execute()

    alt Sequential Process
        ProcessStrategy->>ProcessStrategy: run_sequential()
        loop 顺序执行每个任务
            ProcessStrategy->>TaskExecutor: execute_task()
            TaskExecutor->>Agent: assign_task()
            Agent->>LLM: process_request()

            opt 需要工具调用
                LLM->>ToolManager: invoke_tool()
                ToolManager-->>LLM: tool_result
            end

            LLM-->>Agent: response
            Agent-->>TaskExecutor: task_result
            TaskExecutor-->>ProcessStrategy: task_output
        end
    else Hierarchical Process
        ProcessStrategy->>ProcessStrategy: create_manager()
        ProcessStrategy->>ProcessStrategy: run_hierarchical()
        ProcessStrategy->>Agent: delegate_tasks()
        Agent->>Agent: coordinate_execution()
    end

    ProcessStrategy-->>CrewManager: crew_output
    CrewManager->>EventBus: publish(CrewCompletedEvent)
    CrewManager-->>CLI: final_result
```

## 策略模式 - 执行流程

```mermaid
classDiagram
    class ProcessStrategy {
        <<interface>>
        +execute(tasks) CrewOutput
    }

    class SequentialProcess {
        +execute(tasks) CrewOutput
        -execute_task_sequence()
    }

    class HierarchicalProcess {
        +execute(tasks) CrewOutput
        -create_manager_agent()
        -delegate_tasks()
    }

    class Crew {
        +Process process
        +kickoff() CrewOutput
        -select_strategy()
    }

    ProcessStrategy <|.. SequentialProcess
    ProcessStrategy <|.. HierarchicalProcess
    Crew --> ProcessStrategy : uses

    note for SequentialProcess "按顺序执行任务\n每个任务依赖前一个"
    note for HierarchicalProcess "管理器代理协调\n动态任务分配"
```

## 命令模式 - 任务执行

```mermaid
classDiagram
    class Command {
        <<interface>>
        +execute()*
        +undo()*
    }

    class TaskCommand {
        -Task task
        -Agent agent
        +execute()
        +undo()
    }

    class ToolCommand {
        -BaseTool tool
        -dict args
        +execute()
        +undo()
    }

    class TaskInvoker {
        -List~Command~ commands
        -List~Command~ history
        +invoke(command)
        +undo()
        +redo()
    }

    Command <|.. TaskCommand
    Command <|.. ToolCommand
    TaskInvoker --> Command : invokes

    note for TaskInvoker "支持撤销/重做\n命令历史记录"
```

## 状态模式 - 执行状态管理

```mermaid
stateDiagram-v2
    [*] --> Idle

    Idle --> Planning : start_planning()
    Planning --> Ready : planning_complete()
    Ready --> Executing : begin_execution()

    Executing --> TaskRunning
    TaskRunning --> AgentBusy : assign_agent()
    AgentBusy --> ToolExecuting : use_tool()
    ToolExecuting --> AgentBusy : tool_complete()
    AgentBusy --> TaskComplete : task_done()

    TaskComplete --> TaskRunning : next_task()
    TaskComplete --> Completed : all_done()

    TaskRunning --> Paused : pause_request()
    AgentBusy --> Paused : pause_request()
    Paused --> TaskRunning : resume()

    TaskRunning --> Failed : error_occurred()
    AgentBusy --> Failed : error_occurred()
    Failed --> Idle : reset()

    Completed --> Idle : reset()
```

**设计模式优势说明：**

1. **策略模式**：支持多种执行流程（顺序、层次），便于扩展新的执行策略
2. **装饰器模式**：为代理添加缓存、日志、监控等功能，不修改核心逻辑
3. **观察者模式**：事件系统实现松耦合，便于监控和扩展
4. **工厂模式**：统一LLM创建接口，支持多种模型提供商
5. **命令模式**：任务执行支持撤销/重做，提供更好的错误恢复能力
6. **状态模式**：清晰的状态转换逻辑，便于状态管理和调试

这些设计模式的组合使用，确保了CrewAI框架的高度模块化、可扩展性和可维护性。
