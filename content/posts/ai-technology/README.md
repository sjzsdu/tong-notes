## 主要技术领域

### LangChainGo
LangChainGo 是 Go 语言版本的 LangChain 框架，用于构建基于大语言模型的应用程序。

### MCP (Model Context Protocol)
MCP 是一种标准化协议，用于连接 AI 模型与工具、API 和资源。

### A2A (Agent2Agent)
A2A 是一种开放标准，解决 AI 代理间通信和协作的根本挑战。

### Tong Agent
Tong Agent 是基于 LangChain 的 AI 对话代理命令行工具。
