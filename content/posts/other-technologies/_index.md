## 主要技术领域

### Tidy3D
Tidy3D 是一个用于电磁仿真的 Python 包，提供了强大的 3D FDTD (时域有限差分) 仿真功能。

### YaoApp
YaoApp 是一个低代码开发平台，提供了快速构建 Web 应用的能力。

### Zorro
Zorro 是一个基于 Angular 的组件库，提供了丰富的 UI 组件和工具。
