## 验证流程状态图

```mermaid
stateDiagram-v2
    [*] --> InputReceived
    
    InputReceived --> SchemaValidation : 开始验证
    
    SchemaValidation --> SchemaValid : 结构正确
    SchemaValidation --> SchemaError : 结构错误
    
    SchemaValid --> SemanticValidation
    SchemaError --> ErrorReporting
    
    SemanticValidation --> SemanticValid : 语义正确
    SemanticValidation --> SemanticWarning : 发现警告
    SemanticValidation --> SemanticError : 语义错误
    
    SemanticValid --> PhysicalValidation
    SemanticWarning --> PhysicalValidation
    SemanticError --> ErrorReporting
    
    PhysicalValidation --> PhysicalValid : 物理合理
    PhysicalValidation --> PhysicalWarning : 物理警告
    PhysicalValidation --> PhysicalError : 物理错误
    
    PhysicalValid --> ValidationSuccess
    PhysicalWarning --> ValidationSuccess
    PhysicalError --> ErrorReporting
    
    ErrorReporting --> [*] : 返回错误结果
    ValidationSuccess --> [*] : 返回成功结果
```

验证流程采用渐进式验证策略，从基础结构验证逐步深入到复杂的物理合理性验证，每个阶段都可能产生错误、警告或成功结果。

## 核心验证特性

1. **JSON Schema集成**：基于industry-standard JSON Schema 进行结构验证
2. **自定义验证器**：扩展验证功能，支持CFD特定的验证需求
3. **分级错误处理**：区分错误和警告，提供不同级别的反馈
4. **上下文相关验证**：根据配置上下文进行智能验证
5. **表达式验证**：支持用户自定义表达式的语法和语义验证
6. **物理约束检查**：验证物理参数的合理性和一致性

该验证系统确保了Flow360平台能够可靠地处理各种复杂的CFD配置，提高了计算成功率和结果准确性。
