As a User, I want to measure 3D distances between two points in the 3D viewer so that I can analyze spatial relationships.

Scope

Can click on the entities in the 3D viewer when activating the measure tool

Show the measure panel when users click and snap to the first point

Show X, Y, Z locations of the first point in the panel

Show X, Y, Z locations of the second point in the panel when the cursor symbol is moving (no point selected)

Show X distance, Y distance, Z distance, and 3D distance in the panel

Show 3D distance line symbol and 3D distance text in the viewer if applicable

The values on the panel are read-only

Show the completed measured values when users click and snap to the second point

Can reset the measured values in the panel

Can copy the values in the panel

Can be used in View only and Draft mode

Can store the measure and create another one

Store the measure in the entities list

Users can show/hide, delete the measure
